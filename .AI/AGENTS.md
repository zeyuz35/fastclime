# .AI/ — AI Agent Files

## Structure

- `docs/` — Documentation and reference material
- `plans/` — Plans for future work
- `journal/` — Development history and progress

## Workflow

1. Read `AGENTS.md` (root) first for repository overview
2. Check `plans/` for pending work
3. Check `journal/` for history and context
4. After completing work, update both `journal/` and root `AGENTS.md`
