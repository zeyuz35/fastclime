### Critical Bugs Identified

#### 1. Uninitialized Memory Read — `linalg.c:171`
- **Severity**: High
- **Type**: Memory safety
- **Issue**: `link[-1]` accessed in `Nt_times_y` but `link_buf[0]` never set for first element
- **Status**: **RESOLVED** (2026-04-07)
- **Fix**: Changed `link[jj] = j` to handle first element (jj==-1) separately, set `link[0] = j` for head
- **Verification**: Tests run without segfault

#### 2. Uninitialized Memory Read — `lu.c:981`
- **Severity**: High
- **Type**: Memory safety
- **Issue**: `link[-1]` read in `Gauss_Eta` before write
- **Status**: **RESOLVED**
- **Fix**: Added `link[0] = -1` initialization before loop

#### 3. Division by Zero in LU Solve — `lu.c:662,779,914`
- **Severity**: Critical
- **Type**: Numerical
- **Issue**: `y[i]/diagU[i]` when `diagU[i]==0` (rank < m)
- **Status**: **RESOLVED**
- **Fix**: Added guard `if (diagU[i] == 0.0) { beta = 0.0; } else { beta = y[i]/diagU[i]; }`

#### 4. Division by Zero in LP Solvers
- **Severity**: Critical
- **Type**: Numerical
- **Files**: `dantzig.c:306-311,316`, `fastlp.c:363-377`, `paralp.c:372-386`, `parametric.c:370-384`
- **Issue**: `dx_B[k]` or `dy_N[k]` could be zero
- **Status**: **RESOLVED**
- **Fix**: Added guards (`fabs(denom) > 1e-300`) before dividing, set to `R_PosInf` on degenerate

#### 5. print.fastclime() Both Branches Execute — `R/fastclime.R:152-157`
- **Severity**: Critical
- **Type**: Logic error
- **Issue**: Two separate `if` statements instead of `if/else`
- **Status**: **RESOLVED**
- **Fix**: Changed second `if (!x$cov.input)` to `else`
