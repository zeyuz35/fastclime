## 2026-06-09 - Explicit Namespacing and Dependency Reduction

**Learning:** Implicit namespacing through `import()` in `NAMESPACE` and `Depends:` in `DESCRIPTION` can pollute the global namespace and obscure dependencies. Transitioning to explicit namespacing (`pkg::func()`) and moving dependencies to `Imports:` in `DESCRIPTION` improves package hygiene. Also, the build artifacts like `build/vignette.rds` should be deleted to fix warnings from `R CMD check`, and non-data files in `data/` like `AGENTS.md` should be moved to `inst/extdata/`. Finally, tests that source helper scripts using `../../scratch/...` paths are fragile to `R CMD check` execution environments, so those helpers should be moved or the paths should be fixed (e.g. `tests/testthat/scratch/`).

**Action:** I will move `igraph`, `MASS`, and `Matrix` from `Depends` to `Imports` in the `DESCRIPTION` file, remove `import("Matrix","igraph","MASS")` from `NAMESPACE`, and add explicit namespacing to function calls (e.g., `MASS::mvrnorm`, `igraph::graph_from_adjacency_matrix`, `Matrix::Matrix`) in the R source code. I will also explicitly namespace base utilities like `utils::flush.console()`, `stats::cov2cor()`, and `graphics::image()` to clear R CMD check NOTEs.
