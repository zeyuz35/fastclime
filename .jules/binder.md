## 2026-06-05 - Explicit namespacing and R package data directory hygiene
**Learning:** In R packages, `flush.console()` relies on the `utils` namespace and its implicit use triggers a missing global function definition NOTE during `R CMD check`. Additionally, the `data/` directory must strictly contain data objects; non-data files (like `AGENTS.md`) should be placed in `inst/extdata/` to avoid `R CMD check` warnings.
**Action:** Always explicitly namespace base R utility functions (e.g., `utils::flush.console()`) in package code instead of relying on global resolution, and ensure that only `.RData` or similar data files reside in `data/`, moving any auxiliary configuration or markdown files to `inst/extdata/`. Ensure not to stage compiled artifacts like `.rds` files generated during the build.
