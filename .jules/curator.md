## 2026-06-10 - Preserving Symmetry Checks with Ignored Attributes
**Learning:** `isSymmetric()` strictly requires dimnames to be identical (or NULL). This can cause valid covariance matrices that have `rownames` but no `colnames` (or mismatched dimnames/classes like `zoo` or `xts` time series objects) to falsely evaluate as asymmetric, triggering silent fallback behaviors (e.g., re-calculating the covariance on an already covariance matrix, losing original dimnames and corrupting the matrix).
**Action:** When validating matrix symmetry for structural logic checks (like identifying covariance matrices) where attributes are irrelevant to the mathematical structure, wrap the input in `as.matrix()` and explicitly set `check.attributes = FALSE` via `isSymmetric(as.matrix(x), check.attributes = FALSE)`.
