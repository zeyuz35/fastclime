## 2024-05-23 - Avoid redundant matrix inversions
**Learning:** In mathematical R operations, `solve()` is an O(N^3) operation and should be avoided when the result can be analytically derived. When scaling a precision matrix to a correlation matrix and recalculating its inverse, the second `solve()` can be entirely avoided by scaling the original precision matrix with the square root of the unscaled covariance matrix diagonals via vector-matrix multiplication.
**Action:** Replace `sigma = cov2cor(solve(omega)); omega = solve(sigma)` with `Sigma_unscaled = solve(omega); D_sqrt = sqrt(diag(Sigma_unscaled)); sigma = cov2cor(Sigma_unscaled); omega = t(t(omega * D_sqrt) * D_sqrt)`.
