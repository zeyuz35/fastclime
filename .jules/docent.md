## 2024-05-11 - Enforce one-sentence-per-line in roxygen comments
**Learning:** Roxygen documentation should format long parameter descriptions and details with one sentence per line. Also, mathematical notation like l1 should use `\eqn{\ell_1}` and variables should use `\code{}`.
**Action:** Always break sentences into separate lines in `@param`, `@details`, and `@note` tags to avoid exceeding character limits and improve readability.
