## 2026-06-19 - Use `styler` for R Package Formatting
**Learning:** In R packages, formatting inconsistencies like `=` vs `<-` and spacing issues can be automatically resolved using the `styler` package, which is the standard auto-formatter for R codebases.
**Action:** Always run `styler::style_pkg()` as the Docent persona in R packages to ensure a unified and professional code style before committing changes.
