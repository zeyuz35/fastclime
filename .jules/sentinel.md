## 2024-05-18 - Prevent Zero-Length Memory Allocation Errors
**Vulnerability:** The C memory management macros (`MALLOC`, `CALLOC`, `REALLOC`) passed the `len` parameter directly to `malloc()`, `calloc()`, and `realloc()`. If `len` evaluated to `0`, standard C behavior allows these functions to return `NULL`. This would trigger the macro's error handling condition (`if ((name) == NULL)`), mistakenly causing a fatal R `error()` due to "Memory allocation failed" rather than processing an empty array. Additionally, evaluating the `len` argument multiple times in macro expansion could cause double-evaluation hazards if expressions with side-effects were passed.
**Learning:** Returning `NULL` on a zero-length allocation request can create confusing and application-crashing behaviors (fatal `error()`) instead of safely continuing execution. Standardizing safe lengths and single evaluation using local variables in macros avoids both double-evaluation and erroneous `NULL` error triggers.
**Prevention:** Ensure C macros evaluate arguments strictly once by assigning them to a local typed variable (e.g., `size_t _safe_len = (size_t)(len)`). **Vulnerability:** Core exported R functions (`fastclime`, `dantzig`, `fastlp`, `paralp`) directly passed user input matrices and vectors into internal C solver extensions (`.C()`) without validating array lengths, NA presence, or types. This could cause the C code to attempt matrix operations or memory accesses on NULL pointers, empty objects, or non-numeric types, triggering fatal segmentation faults that crash the entire R session (Denial of Service).
**Learning:** In C extensions, missing or invalid input validation in the wrapper R layer exposes raw C loops to boundary/type assumptions that are easily violated. Ensuring strictly numeric, non-empty, NA-free matrices at the entry point of R packages hardens the C-level algorithms against malicious or malformed inputs.
**Prevention:** Use explicit `stopifnot()` checks in R wrappers before `.C()` boundaries to enforce minimum length (`length(x) > 0`), object type (`is.numeric(as.matrix(x))`), and clean values (`!anyNA(as.matrix(x))`).
