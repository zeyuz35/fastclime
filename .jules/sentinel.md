## 2024-05-18 - Prevent Zero-Length Memory Allocation Errors
**Vulnerability:** The C memory management macros (`MALLOC`, `CALLOC`, `REALLOC`) passed the `len` parameter directly to `malloc()`, `calloc()`, and `realloc()`. If `len` evaluated to `0`, standard C behavior allows these functions to return `NULL`. This would trigger the macro's error handling condition (`if ((name) == NULL)`), mistakenly causing a fatal R `error()` due to "Memory allocation failed" rather than processing an empty array. Additionally, evaluating the `len` argument multiple times in macro expansion could cause double-evaluation hazards if expressions with side-effects were passed.
**Learning:** Returning `NULL` on a zero-length allocation request can create confusing and application-crashing behaviors (fatal `error()`) instead of safely continuing execution. Standardizing safe lengths and single evaluation using local variables in macros avoids both double-evaluation and erroneous `NULL` error triggers.
**Prevention:** Ensure C macros evaluate arguments strictly once by assigning them to a local typed variable (e.g., `size_t _safe_len = (size_t)(len)`). Also, enforce a minimum allocation size of 1 element (`_safe_len = _safe_len > 0 ? _safe_len : 1;`) so `NULL` is only returned on actual Out-Of-Memory events, and never on legitimate `0`-length requests.## 2026-04-10 - Prevent Integer Overflows in C Array Allocations
**Vulnerability:** Passing calculated dimensions (e.g., `N * N + m`) as arguments to memory allocation macros can trigger an integer overflow before the internal `size_t` casts or safety checks execute in 32-bit `int` arithmetic, resulting in dangerously undersized allocations. Additionally, `SIZE_MAX` is not guaranteed to be defined portably without explicit `<stdint.h>` inclusions.
**Learning:** Math operations on 32-bit integers in macro arguments are resolved prior to any internal `size_t` parameters inside the function/macro.
**Prevention:** Cast multiplication operands to `size_t` prior to execution (e.g., `(size_t)N * N + m`) and replace `SIZE_MAX` with `((size_t)-1)` to portably represent the maximum value without `<stdint.h>`.
